# “我的”页 UI 设计说明

## 设计目标

将原有的功能卡片列表升级为正式的校园生活服务中心。页面不照搬会员体系，也不使用霓虹、玻璃拟态和大面积渐变等常见模板效果；视觉关键词为“可靠、年轻、校园、克制”。

## 信息层级

1. 身份区：品牌、系统头像、鹏宇用户编号、默认宿舍地址与退出入口。
2. 数据概览：商品、帖子、收藏数量，同时作为内容筛选快捷入口。
3. 校园服务：宿舍地址、订单、消息、规则说明四个高频入口。
4. 运营工作台：仅管理员可见，集中商品库存与订单履约。
5. 我的内容：分段切换商品、帖子、收藏，包含加载骨架、数据列表和可行动的空状态。

## 视觉系统

- 主色：深松绿 `#123D32`，传递稳定与校园生活感。
- 交互色：玉石绿 `#176347`，用于选中状态和主按钮。
- 强调色：奶油金 `#F2C879`，只用于身份、管理员和局部装饰。
- 背景：灰绿白 `#F3F6F4`，卡片使用纯白并搭配低对比边框。
- 圆角：主卡片 22–24rpx，品牌头图底部 48rpx，按钮按用途使用胶囊或 12–16rpx 圆角。
- 文字：中文承担信息传达，极少量英文作为栏目眉题，建立稳定的编辑式节奏。

## 交互与状态

- 点击宿舍胶囊和服务入口均可修改默认地址。
- 数据概览与内容分段控件保持同步。
- 加载期间展示骨架卡片，避免空状态闪烁。
- 三类空状态均提供下一步操作：发布商品、发布帖子、前往市场。
- 退出登录增加确认，减少误触。
- 小屏设备隐藏次级说明，并将管理员入口改为单列。
