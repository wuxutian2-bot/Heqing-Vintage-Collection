# 帖子详情窄屏操作区修复设计

## 问题

帖子详情的内容治理卡片把说明文字和两个按钮放在同一横排。小屏下按钮占据固定宽度，说明区域被压缩到单字宽度，形成竖排文字和按钮溢出。私聊按钮则在当前用户就是作者时直接隐藏，用户无法判断是功能缺失还是产品禁止自聊。

## 方案比较

1. 推荐：治理卡改为上下两层，说明独占一行，操作按钮在下一行等宽排列；私聊区域保留两个位置，自有帖子显示不可点击的“这是你的帖子”，他人帖子显示“私聊作者”。信息明确，改动局部且不改变云端安全规则。
2. 始终显示“私聊作者”，点击自己的帖子后由云端报错。实现最少，但会把可预防错误暴露给用户，体验较差。
3. 把管理动作移入右上角菜单。页面更简洁，但入口隐蔽、改动范围大，不适合当前缺陷修复。

## 验收

- 360px 左右窄屏下“内容治理”保持横向可读，按钮不越出卡片。
- 管理员看到置顶和删除两个等宽操作；普通作者只看到删除操作。
- 查看他人帖子显示“私聊作者”；查看自己的帖子显示“这是你的帖子”，且不发起自聊。
- 点赞、浏览量、评论区及云端管理员鉴权保持原逻辑。
