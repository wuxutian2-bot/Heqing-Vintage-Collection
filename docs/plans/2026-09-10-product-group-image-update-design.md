# 商品组图片统一更换设计

## 目标

在“商品与库存”管理页编辑任意一条商品记录时，总管理员上传一次新图片，即可把图片同步到当前学校所有代售点中的同款商品。各代售点仍独立维护价格、库存和上下架状态。

## 识别与范围

- 商品库中的标准商品以 `sku` 作为同款标识。
- 批量创建的自定义商品以 `productGroupId` 作为同款标识。
- 云函数根据被编辑记录自行推导标识，前端不能提交任意查询条件。
- 更新范围限制为管理员所属学校的代售点，最多 16 条；缺少统一标识或存在异常重复记录时拒绝批量操作。

## 操作流程

1. 总管理员在现有商品编辑表单选择并上传新图片。
2. 点击“统一更换全部代售点图片”。
3. 云函数预览匹配范围，界面展示商品名称及预计影响的代售点数量。
4. 管理员确认后，前端携带记录 ID、云文件 ID 和预期数量请求更新。
5. 云函数重新校验权限与范围，只更新 `image` 和 `updatedAt`。

## 安全与异常处理

只接受 `cloud://` 图片文件 ID；批量更新仅限总代售点管理员。执行前后使用预期数量校验，避免数据变化或重复数据造成误更新。普通代售点管理员仍只能修改本代售点库存及上下架状态。
