# 校园圈本周热议设计

## 目标

将校园圈“今日热议”升级为“本周热议”。头图下方始终只展示一条热议，最多从近7天内容中取10条并自动纵向循环；用户点击当前话题进入帖子，点击右侧“榜单”打开完整前十排行榜。

## 数据规则

云函数新增 `weeklyHot` 操作，读取最近100条候选，过滤创建时间在近7天内的帖子，按 `浏览量 + 评论数×5 + 点赞数×3` 排序，分数相同时按发布时间倒序，返回前10条。结果继续复用作者补全逻辑，兼容旧帖子作者字段。

## 交互与视觉

使用单条纵向 `swiper`，多于1条时每3.5秒自动切换并循环播放。右侧“榜单 ›”保持固定，不随轮播变化；榜单使用当前页底部弹层，列出名次、标题和浏览/评论/点赞数据，点击任意条目进入详情，点击遮罩或关闭按钮返回。无数据时保留“本周话题”发布引导。

## 验收

- 轮播每次只显示一条，最多10条，标签为“本周热议”。
- 榜单可列出相同的前十内容，点击可进入帖子详情。
- 云端只返回近7天帖子，不能由前端伪造排序或跨周内容。
- 作者头像、副名称、原有搜索/分类/发布功能不受影响。
