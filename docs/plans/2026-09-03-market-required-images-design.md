# 校园闲置图片必填与展示修复

## 目标

校园闲置商品必须至少上传一张实物图片才能发布。上传成功的云存储图片需要在市场列表和商品详情中稳定显示。

## 方案

发布页在提交前检查图片数组，并明确标注“必填 · 至少1张”。云函数再次校验图片，避免绕过客户端直接提交无图商品。只接受云文件 ID 或 HTTP(S) 图片地址，最多保留九张。

新上传的图片以 `cloud://` 文件 ID 持久化，查询列表或详情时由商品云函数批量转换为临时 HTTPS 地址后返回前端。转换失败时保留原文件 ID并记录错误，避免影响商品接口的其他数据。返回市场页时只要当前不在加载，就重新拉取第一页，确保原市场为空时发布的第一件商品也会立即出现。

## 验收

- 未选择图片时，发布页提示“请至少上传1张商品图片”且不发起提交。
- 绕过客户端提交空图片时，云函数拒绝创建商品。
- 携带图片发布成功后，市场卡片与商品详情均返回并使用可显示的 HTTPS 地址。
- 图片上传没有返回文件 ID时，发布中止并提示重试。
- 发布完成返回市场后立即刷新，包括发布前市场为空的情况。
