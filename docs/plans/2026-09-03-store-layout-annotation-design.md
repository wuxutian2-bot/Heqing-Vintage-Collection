# 代售点首页截图标注调整

## 目标

根据截图标注优化代售点首页的三处比例：搜索框使用输入区70%、搜索按钮30%的7:3布局；商品加号保持紧凑圆形；购物车和管理操作栏向底部导航靠近，减少页面中间空白。

## 实现

搜索输入设置为可伸缩并允许收窄，搜索按钮锁定30% flex basis及宽度。加号按钮锁定54rpx的宽高、字号28rpx，避免被按钮默认样式拉伸成横向椭圆。购物车和管理按钮放入同一行并等宽分配，使用带安全区的16rpx底部偏移，贴近截图中的底部空白区且不遮挡导航。

## 验收

- 搜索输入与搜索按钮视觉比例约7:3。
- 商品加号为小圆形，不再横向占满商品行。
- 购物车/管理按钮等宽同排、整体下移且不遮挡底部导航。
- 商品点击、搜索、购物车和管理跳转功能不变。
