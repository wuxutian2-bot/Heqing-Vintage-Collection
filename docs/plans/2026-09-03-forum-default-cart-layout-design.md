# 校园圈默认页与购物车标注调整

## 目标

小程序冷启动时直接展示校园圈，同时保留现有五项底部导航顺序。购物车页面根据截图调整三个操作位置：清空按钮改成醒目的红底白字；数量步进器放到价格下方左侧；移除按钮放到商品卡片内容区最右侧。

## 布局方案

启动页通过 `app.json` 的页面注册顺序控制，将校园圈设为第一项；登录页没有可返回页面或返回失败时也统一跳到校园圈。购物车商品行只调整操作区顺序与对齐，不改数量和删除逻辑。底部结算栏保留商品小计，右侧操作区使用 7:3 网格：“去结算”占左侧七成，右侧三成用无内容占位区保留给后续优惠券入口，当前不展示不可点击的假按钮。

## 验收

- 冷启动和登录兜底均进入校园圈。
- 清空按钮为红色背景，原清空确认弹窗不变。
- 数量控件位于价格下方左侧，移除按钮位于最右侧。
- 结算操作区严格按 7:3 分栏，右侧预留区不会遮挡结算按钮。
- 自动化测试验证页面顺序、登录兜底、控件顺序和关键布局比例。
