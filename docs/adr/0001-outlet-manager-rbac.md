# ADR-0001：代售点采用两级角色与单点资源范围

## 状态

Accepted

## 背景

现有 `admin` 可以管理全部代售点和商品，无法安全地把单个代售点交给普通管理员。需要在不增加新服务和复杂权限后台的前提下阻止跨点库存操作。

## 决策

保留 `admin` 为总管理员；新增 `outlet_admin`，使用 `users.managedOutletId` 绑定唯一代售点。`store` 云函数集中执行角色检查和资源归属检查。普通管理员只能初始化本点、修改本点库存和上下架状态。

## 结果

### 正面

- 角色发放简单，开发者只需修改一条用户文档。
- 商品写入通过真实文档归属鉴权，前端伪造 `outletId` 无效。
- 不破坏现有总管理员和普通用户。

### 负面

- 一个普通管理员当前只能管理一个代售点。
- 角色修改后需要用户重新登录刷新本地展示状态。

### 中性

- 如果未来需要一人管理多个代售点，可把字段升级为 `managedOutletIds`，云函数鉴权接口保持不变。

## 备选方案

- 权限字符串数组：当前规模下维护成本过高。
- 按楼栋号授权：不是稳定资源标识，拒绝采用。
