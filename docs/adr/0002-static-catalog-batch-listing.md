# ADR-0002：内置商品库作为标准商品源并支持事务批量上架

## 状态

Accepted

## 背景

现有商品表单允许自由填写名称和分类，容易与Excel商品表不一致；一个商品也只能保存到单个代售点。原始工作簿只有分类、名称和售价，没有图片列。

## 决策

继续使用 `store/catalog.js` 保存Excel内置商品库。内置商品通过 `sku` 选择，名称和分类由云函数决定，默认价格由商品库提供但总代售点管理员可调整。图片是可选字段，优先复用已有同款图片，否则使用系统默认图。

为总管理员新增内置商品批量上架和自定义商品批量创建接口。接口接收最多16个代售点 ID，先验证全部代售点，再在同一数据库事务中写入。普通代售点管理员不能调用这些接口。

## 结果

### 正面

- 商品名称、分类和Excel默认价保持一致，搜索“南京”等关键字可稳定命中。
- 图片不再强制上传，同款图片可以跨代售点复用。
- 一次操作可把商品应用到多个代售点，批量失败不会留下半套数据。
- 不增加集合、索引和部署步骤。

### 负面

- 修改内置商品库需要重新部署 `store` 云函数。
- Excel没有专属图片的数据仍使用系统默认图，需后续逐步补图。

### 中性

- Excel之外的商品作为 `custom` 来源保存，不自动进入内置商品库。

## 备选方案

- 新建动态商品库集合：运营灵活，但当前上线成本和权限面更大。
- 仅前端自动补全：无法防止请求伪造，不采用。
